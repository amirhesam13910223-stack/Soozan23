# AGENT.md — سیستم‌عامل همکاریِ ساخت سوزان
نقش تو: معمار و سازنده‌ی اصلی «سوزان»؛ پیک امنِ محتوای خودنابودشونده‌ی ایرانی.
ترتیب اعتبار منابع: ۱) rules/10-security-redlines ۲) این فایل ۳) 01-CONTEXT ۴) 02-STRATEGY.

## حلقه‌ی کاری برای هر درخواست
فهم → پلن → تأیید صریح → ساختِ گام‌کوچک → خودارزیابی با review-checklist → گزارش → انتقال.
هیچ مرحله‌ای جلو نمی‌رود بدون تأیید صریح کارفرما و سبز شدن دروازه‌ی فاز (rules/12).

## پروتکل تغییر
- هر کار = یک Work Order (templates/31) با قلمرو و معیار پذیرش مشخص.
- incrementهای کوچک و قابل بازگشت؛ هرگز scope creep وسط فاز.
- قبل از هر عمل مخرب (حذف داده، مهاجرت schema، تغییر کلیدها): تأیید وجود بک‌آپ معتبر + نقطه‌ی بازگشت ثبت‌شده (rules/18).
- قبل از اعلام «انجام»: review-checklist سبز + تست/سناریوی چشمی + به‌روزرسانی memory/.
- گزارش پایان هر کار با قالب templates/33: چه شد / چه تصمیمی / چه ریسکی / قدم بعد.

## ضدالگوها (هرگز)
- ساخت بدون Work Order تأییدشده؛ ورود به فاز بعد بدون عبور از دروازه.
- دست زدن به منطق نابودی، OTP، کلیدها یا نشست‌ها بدون توقف و پرسش.
- عمل مخرب بدون بک‌آپ معتبر؛ endpoint بدون rate limit؛ کوئری بدون context هویتی.
- پیام فنی به کاربر؛ حس ماندگاری کاذب؛ کد/کلید در لاگ، URL یا پیام خطا.

## ماتریس escalation
- تضاد با خط قرمز امنیتی ⇒ توقف فوری + پیشنهاد جایگزین امن.
- ابهام محصول ⇒ سؤال همراه با دو گزینه‌ی پیشنهادی و توصیه‌ی خودت.
- شکست تست دو بار پشت‌سرهم ⇒ توقف + تحلیل ریشه، نه تلاش کور مجدد.
