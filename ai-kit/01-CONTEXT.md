# CONTEXT.md — زمینه‌ی operative سوزان
ماهیت: پیک امن یک‌بارمصرف؛ محتوا می‌آید، دیده می‌شود، می‌سوزد. وعده: «بفرست، بدون اینکه جا بماند.»
نقش‌ها: فرستنده (با حساب) / گیرنده (بدون حساب، بدون ردپا) / نگهبان (مدیر، فقط فراداده).
کدها: کد اشتراک ۶۴ کاراکتری (فقط یک‌بار نمایش، بازیابی‌ناپذیر)؛ کد مدیریت؛ OTP شش‌رقمی.
منابع مکمل: سیستم طراحی و ناوبری در 03-DESIGN.md؛ تصویر مرجع ناوبری در refs/nav-reference.png.

## ماشین‌های حالت (مرجع رفتار)
OTP: PENDING(120s، ۴ تلاش) → LOCKED یا EXPIRED → فقط resend → PENDING جدید؛ SUCCESS ⇒ پاک‌شدن اسلات.
اشتراک: draft → scanned(اسکنر) → sealed(رمزنگاری) → issued(صدور کد) → consuming(بازدیدها) → burned/expired.
دریافت: code → validate → (رمز فایل) → view → count → burn.
نشست: anonymous → authed → trusted-device → revoked («پایان همه نشست‌ها» همه را فوری باطل می‌کند).

## اپلیکیشن (تجربه‌ی اصلی)
ورود هوشمند: نشست معتبر و «به خاطر سپردن» ⇒ مستقیم خانه؛ وگرنه صفحه‌ی ورود/ثبت‌نام.
ناوبری: نوار پایین = کپسول شناور گرد با بلور و حاشیه‌ی نازک مطابق refs/nav-reference.png؛
آیتم‌ها (آیکون بالای برچسب فارسی): «خانه | کد مدیریت | دریافت فایل»؛ آیتم فعال = pill اکسنت لغزشی.
FAB دایره‌ای اکسنت شناور بالای نوار، سمت چپ (پایان RTL) ⇒ مستقیم به ویزارد اشتراک.
دریافت فایل کاملاً بدون حساب/ورود است؛ گیرنده ردپا نمی‌گذارد.
ورود: الف) کامل هر بار (نام کاربری+رمز+OTP) ب) یک‌باره با اعتماد به دستگاه ج) بیومتریک/پین/الگوی گوشی (فقط قفل محلی، هرگز هویت سرور نیست).
تنظیمات حساب شامل «پایان همه نشست‌ها» است: همه‌ی دستگاه‌ها فوراً باطل + ورود کامل اجباری برای بازگشت.
محافظت نمایش: ضد اسکرین‌شات/ضبط صفحه؛ صفحه سیاه در پس‌زمینه/سویچر؛ واترمارک به‌عنوان لایه‌ی بازدارنده.

## نسخه‌ی وب (فقط اشتراک)
دامنه: فقط جریان اشتراک فایل + مدیریت حساب فرستنده؛ دریافت فایل فقط در اپ.
ناوبری: همان کپسول شناور ولی بدون «دریافت فایل» ⇒ «خانه | کد مدیریت» + FAB ویزارد.
پنجره‌ی توجه: هر بازدید وب ⇒ پیام «دریافت فایل نیاز به اپ دارد؛ گیرنده هم باید اپ داشته باشد»؛
همیشه نمایش داده می‌شود مگر تیک ماندگار «این پیام دیگر نمایش داده نشود» زده شود.
یادآور متنی: در صفحه‌ی نمایش کد اشتراک/کد مدیریت، همان پیام به‌صورت بخش برجسته‌ی متن صفحه هست (نه پنجره).

## ویزارد اشتراک فایل
گام ۱ فایل: تصویر/ویدیو/صدا/اسناد/کد/آرشیو مجاز؛ اجرایی‌ها ممنوع؛ سقف حجم per-type؛ نمایش نوع و اندازه.
گام ۲ نابودی: بازدید / زمان / هر دو / دلخواه (سقف بازدید + مدت + واحد)؛ پریست‌ها: یک‌بارمصرف، ۲۴ ساعته، هفتگی، دلخواه.
گام ۳ محافظت/شخصی‌سازی: رمز فایل، واترمارک، یادداشت، پیام‌های شخصی گیرنده، سقف تلاش رمز.
گام ۴ بازبینی خوانا؛ گام ۵ صفحه‌ی کد: کد اشتراک ۶۴ کاراکتری (فقط همین‌یک‌بار) + کد مدیریت + یادآور متنی اپ.

## اسکنر بدافزار (پیش از seal)
هفت مرحله: تطبیق هویت (magic bytes)، امضا، هیوریستیک، بازرسی بازگشتی آرشیو با سقف، ماکروی اسناد، polyglot/لایه پنهان، حکم نهایی (تمیز/قرنطینه/رد).
اسکنر فایل را اجرا نمی‌کند؛ محیط ایزوله؛ حکم‌ها در ممیزی؛ اسکن مجدد پس از به‌روزرسانی امضاها؛ تحویل به گیرنده فقط با حکم «تمیز».

## داشبورد (خانه)
فهرست فایل‌ها با وضعیت زنده (فعال/سوخته/منقضی)، بازدید مصرف‌شده، زمان باقی‌مانده، فیلتر/جستجو؛
جزئیات هر فایل؛ مدیریت با کد مدیریت (حذف فوری، رویدادها)؛ آمار کلی مصرف و فضا.

## بخش‌هایی که باید کامل ساخته شوند (نه نمادین)
مرکز راهنما (راهنما، تور، FAQ، جستجو)؛ مانیتایزیشن (اشتراک ماهانه/سالانه، بسته، برند سفید، API پولی، تعرفه شفاف، مدیریت اشتراک توسط کاربر)؛ باشگاه مشتریان (امتیاز، رفرال دوطرفه، نشان‌ها، رویدادها)؛ یکپارچگی ایتا (ربات اعلان، اتصال امن حساب، اشتراک کد در گفت‌وگو)؛ بتا/عرضه (waitlist، دعوت‌نامه، بازخورد)؛ رشد/عملیات (تحلیل بدون نقض حریم، A/B، runbook).

## برند و taxonomy پیام
برند: فارسی RTL از ابتدا؛ آرام و سینمایی؛ جدی اما گرم؛ کم‌حرف و خوش‌عمل؛ هرگز حس ماندگاری کاذب.
taxonomy پیام: status (خبر) / error (راه‌حل) / success (تأیید کوتاه) / empty (دعوت به اقدام) / loading (اطمینان جریان)؛ لحن هر کدام در rules/11.
